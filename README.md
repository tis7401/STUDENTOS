# STUDENTOS

### An AI-Integrated Academic Management and Adaptive Learning Platform

STUDENTOS is a web-based platform designed to help university students manage their academic responsibilities and improve their learning habits through personalized AI-assisted support.

## Technology Stack

- **Frontend:** React.js, HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **AI Integration:** Gemini API (planned)
- **API Testing:** Postman
- **Version Control:** Git and GitHub
- **Deployment:** Vercel and Render

## Main Features

1. Integrated AI Academic Recommendations
2. Adaptive Study Planning
3. Lecture-to-Quiz Learning Cycle
4. Attendance and Progress Risk Insights
